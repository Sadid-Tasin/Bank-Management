# Bank Management System

A university academic project built with Java, Spring Boot, Next.js, and Supabase PostgreSQL.

## Project Structure

- backend/ — Java Spring Boot application
- frontend/ — Next.js frontend
- database/ — Database schema and SQL scripts
- docs/ — Project documentation

## Technology Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- Supabase
- Next.js
- Tailwind CSS
